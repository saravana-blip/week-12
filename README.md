 # Tableau Dashboard Analysis

## 1. Project Overview

This project presents a data visualization dashboard created using **Tableau Public**. The purpose of the dashboard is to organize and visualize data through charts and graphs, making it easier to understand patterns, compare categories, and identify useful insights.

## 2. Dashboard Link

**Tableau Public Dashboard:**
https://public.tableau.com/views/dashboardsheets_17914407850580/Dashboard1

## 3. Objectives

* To visualize the dataset using appropriate charts and graphs.
* To compare different categories and variables.
* To identify patterns and variations in the data.
* To present information through an interactive dashboard.
* To support data interpretation and informed decision-making.

## 4. Tools and Technologies

* **Tableau Public:** For creating and publishing visualizations.
* **Dataset:** The dataset used for the dashboard analysis.
* **README.md:** For documenting the project, methodology, findings, and conclusion.

## 5. Procedure

1. Collected the dataset required for analysis.
2. Imported the dataset into Tableau.
3. Checked the data fields and identified relevant dimensions and measures.
4. Created individual worksheets using suitable charts and graphs.
5. Added chart titles, labels, colours, and legends for clarity.
6. Combined the worksheets into a single dashboard.
7. Reviewed the visualizations to identify patterns, comparisons, and trends.
8. Published the completed dashboard on Tableau Public.

## 6. Key Business Insights

The following points should be completed using the actual results shown in the dashboard.

1. **Category Comparison:** Identify the category with the highest and lowest values.
2. **Trend Analysis:** Describe any increase, decrease, or fluctuation shown in the charts.
3. **Performance Analysis:** Identify the categories or groups showing comparatively strong or weak performance.
4. **Distribution Analysis:** Explain how the observations are distributed across the selected categories.
5. **Decision-Making Insight:** State how the findings could help stakeholders make better decisions.

*Note: These are insight categories, not verified findings. The actual observations must be based on the dashboard data.*

## 7. Conclusion

The Tableau dashboard provides a visual approach to understanding and analysing data. The use of different charts and graphs makes it easier to compare variables, identify patterns, and communicate findings. Bringing the worksheets together into one dashboard improves the presentation and accessibility of information. Overall, this project demonstrates the importance of data visualization in transforming raw data into meaningful insights that can support decision-making.
